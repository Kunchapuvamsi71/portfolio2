# Interactive LMS Course & Quiz Engine

EdTech Web Engineering platform built with **HTML5**, **CSS3**, and modular **JavaScript**.

## 📌 Architecture Overview

```
lms-course-quiz-engine/
├── src/
│   └── engine.js       # Quiz assessment & student analytics engine
├── index.html          # Web UI course platform
└── README.md           # Documentation
```

## ⚡ Features

* **Course Catalog:** Interactive module listing with duration and progress metrics.
* **Assessment Engine:** Evaluates quiz responses, calculates percentage scores, and returns pass/fail metrics.
* **Zero Dependencies:** Pure vanilla JavaScript & HTML5.
